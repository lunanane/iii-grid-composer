What it is

Grid Composer is an iii script for the monome grid, conceptually descended from the 12-year-old Grid Ninja. It revisits that live set with one long-wanted addition: a chord/arp tracker-style sequencer that defines a lead scale for the rest of the instrument, making genuine scale progressions playable rather than fixing everything to a single pre-selected key.

The chord/arp engine borrows the step-capture idea from the Polyend Tracker. Each tracker step stores not just a chord but its key, scale, groove and velocity pattern, so an eight-stage progression can move through harmony as well as rhythm.

Three further sequencers sit around it. A polyrhythmic drum sequencer provides per-track loop lengths, ratcheting and snap-back to MIDI clock. A performance page, informed by the OXI One, gathers global transpose, every mute, and eight animated faders whose eased timing drives fast, musical parameter changes. And three monophonic sequencers, each locked to the lead scale, provide simple melodic lines with their own velocity patterns.

DISCLAIMER. The script was developed with the help of Gemini and Claude, primarily to fit this much functionality into the very limited memory of an iii script. My role was essentially that of UI designer; each round of feature work was followed by an AI-assisted compression pass.

Animated faders & banks — (9–16, *)

Eight vertical faders. Press any cell to set a target; the value eases to it over ~0.5 s, independent of clock — that's the rhythmical fast-parameter feel. Each fader streams a MIDI CC on channel 1. The menu switches between 5 fader banks, so the eight faders address CC 20–27, 28–35, 36–43, 44–51 and 52–59 in turn.

Mutes & transpose — (1–8, 1–7)

Row 1 mutes the six drum tracks. Rows 2–5 are the Arp and Mono 1–3: column 1 mutes the voice, columns 2–8 transpose it (0 at centre column 5, ±3 steps). Row 6 is the multiplier ×1–×8 — how many semitones each transpose step is worth. Row 7 is a global transpose over everything.

03 Page three

Chord/Arp Tracker-Sequencer

This is an accumulation of me trying to understand chord progression.

There are concepts in here inspired by Arplus by Zlosynth (check out their amazing module and manual), and the Chordality app, which explores the same ideas by arranging chords on the circle of filth (the Camelot Wheel). I've worked with harmonic mixing for ages in my DJ sets and live-set planning, and wanted to finally integrate it into a live playing instrument. A limitation many sequencers have — like the amazing Polyend synth, also an inspiration — is that you can't progress between scales; you only play within one scale once it's set. Here, you can.

Start here — the three play modes

It's maybe not obvious at first, but there are multiple levels of playability, switched on the Playmode Modifier at column 14, rows 5–7:

1
Scale arrangement — the default. Each pad in the Playing Area is its own key (the Camelot layout); pressing one sets the working scale and plays the selected chord in it. This is how you move through scale progressions.
2
Locked scale — locks the last-played scale. You now play diatonically within it, in the same circle-of-filth arrangement, so every pad gives a chord that belongs to that one key. Lock it by holding the centre pad (14,6) and pressing a key.
3
Note grid — inspired by how the Plinky handles custom chords. Still locked to the scale you last played, but the layout changes: notes rise within each column and each column is offset from the next, so you can hold any combination and play fully in-key custom voicings. Plinky-light. Here chord settings don't apply, but arp settings do.

Levels 1 and 2 both draw from the Chord/Arp Settings: they either play the selected chord directly, or — when the arpeggiator is active — use that chord as the source for the arp.

The page at a glance

Five regions: the Playing Area (chord roots / scale keys), the Chord/Arp Settings (type, speed, direction, voicing size), the Groove/Velocity Patterns, the Tracker-Sequencer, and the Playmode Modifiers.

The Camelot Wheel

The Playing Area is laid out on the Camelot Wheel of harmonic mixing. Major keys (the B ring) and minor keys (the A ring) alternate by column, and neighbours sit a fifth or a relative major/minor apart — so wandering around the grid moves you through related keys and keeps progressions musical.

Tracker-Sequencer — (9–12, 1–8)

Eight stages, top to bottom. Press a cell to write the current chord and all its settings — chord type, key, scale, groove, velocity, speed, direction — into that stage; the column (1–4) sets the stage's duration in bars. Running, the stages chain into a progression. Hold a stage to edit it; in menu mode, tap a stage to clear it. This per-step capture of groove, velocity, chord type, key and scale is the part I'm proudest of.

Chord type — (1–4, 7–8)

Eight single-button types; hold the ROOT pad (1,7) and tap another for the extended colours. While a root is held, changing the type re-voices live. Full tables in §05.

Chord/Arp Settings & modifiers

At (5–8, 1–4): type (chord / arp / arp+octave / off), speed, direction (up / down / up-down / pattern), voicing size (5/4/3/2). At (13–16, 5–7): Playmode (col 14), Inversion dial (col 15), Key octave (col 16). Run/Stop is (13,8).

Inversion & octave

The inversion dial (15,5–7) rotates voicings; the key-octave radio (16,5–7) shifts the whole chord ±1 octave. Both apply to whatever is playing.

Velocity patterns — the function

Velocity is computed, not stored — sixteen accent shapes from one global function vgv(g, i, base), where g is the pattern (1–16), i the step, base the nominal velocity. Pattern 1 returns the base flat; the rest map a shape sh ∈ [0,1] into velocity 76–108 (≈ 60–85%).

-- g=1 → flat. n = g-1, p = step phase (0..15)
if n <= 4  -- hard accents: every k-th step (k = 4,2,8,3)
   k = {4,2,8,3}[n];      sh = (p % k == 0) ? 1 : 0.15
elseif n <= 8  -- offset / syncopated accents (phase-shifted)
   sh = ((p - offset) % k == 0) ? 1 : 0.2
elseif n <= 12 -- smooth swells
   sh = (math.sin(p/16 · f · 2π) + 1) · 0.5
else           -- build-ups: quarter-note pulse ∨ sine
   sh = max( p%4==0 ? 1 : 0 , (math.sin(…) + 1)·0.35 )
return math.floor(76 + 32 · sh + 0.5)

By band: patterns 2–5 are hard parity/quarter accents, 6–9 offset accents, 10–13 sine swells, 14–16 build-ups. No lookup tables — it's all math.sin and phase modulo, which is what keeps it inside the iii memory budget.

Note length. Drum hits are short triggers. Chord and arp notes are gated by velocity — louder notes ring a touch longer — so dense grooves stay clean.
